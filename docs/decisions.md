# Decisions

Short log of choices and why. Newest at the bottom.

| Date       | Decision                                                                                        | Why                                                                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10-28 | Name the project Overpass_Game everywhere                                                       | "Overpass" alone already means the OSM API                                                                                               |
| 2026-10-28 | Phaser 4 + TypeScript (strict) + Vite                                                           | Familiar engine; strict types for AI-written code                                                                                        |
| 2026-10-28 | Sim is framework-free; Phaser only draws                                                        | Deterministic, testable rules; reproducible bugs                                                                                         |
| 2026-10-29 | TypeScript pinned to 6.x                                                                        | typescript-eslint doesn't support TypeScript 7 yet                                                                                       |
| 2026-10-29 | pnpm 12 workspaces, npm removed                                                                 | Shared packages without publishing; plan decision                                                                                        |
| 2026-10-29 | Playwright boot tests use the dev server with `reuseExistingServer` locally                     | Keeps local runs fast; CI always starts its own server                                                                                   |
| 2026-10-29 | Game `base: './'`                                                                               | itch.io zip uploads need relative asset paths                                                                                            |
| 2026-10-29 | Studio port 5174                                                                                | Lets the Studio and game dev servers run side by side                                                                                    |
| 2026-10-29 | M0 closed before its CI run                                                                     | GitHub Actions minutes exhausted this month; `pnpm check` passes locally. Confirm CI green on the first push.                            |
| 2026-10-29 | Clock carries the fractional tick between calls                                                 | Tick count depends only on total elapsed time, not on frame size                                                                         |
| 2026-10-29 | Roads connect by shared edge only                                                               | Matches the grid model; no separate connection points                                                                                    |
| 2026-10-29 | Graph is derived data, rebuilt locally on change                                                | Keeps the sim simple; incremental result is checked against a full rebuild                                                               |
| 2026-10-29 | Canonical edge direction: smaller endpoint to larger                                            | Makes incremental and full builds comparable                                                                                             |
| 2026-10-29 | Parks are buildable                                                                             | Parks are decorative; spawn-blocking behaviour comes with M3                                                                             |
| 2026-10-29 | Input feel constants live in `apps/game/src/input/config.ts`                                    | Slop, long-press and wheel rate shape gesture reading, not game rules, so they stay out of the sim config                                |
| 2026-10-29 | Touch: draw starts after slop; still hold erases; 2nd finger cancels stroke                     | Keeps draw vs pan conflict-free; a cancelled stroke never reaches the sim                                                                |
| 2026-10-29 | Camera math is pure (`apps/game/src/view/camera.ts`); Phaser mirrors it                         | Fit, pan and zoom-about-pointer are unit-tested without a browser                                                                        |
| 2026-10-29 | Resize refits an untouched camera; a moved one keeps its centre                                 | Rotation shows the whole map until the player takes control, then never yanks the view                                                   |
| 2026-10-29 | `TILE_SIZE` (32 world units) lives in `render-style`                                            | Sizes are shared drawing data for the game and the Studio preview                                                                        |
| 2026-10-29 | Pointer input is read from DOM pointer events on the canvas, not Phaser's input                 | Gives exact pointerType, pointerId, button (incl. pen eraser) and multi-touch; Phaser only draws                                         |
| 2026-10-29 | Roads are placed as the stroke moves; a cancelled stroke rolls back its undo log                | Immediate feedback; corrects the earlier plan to commit only on stroke-end                                                               |
| 2026-10-29 | Stroke halts at a refusing tile (water, mountain, out of bounds, budget)                        | Each tile still goes through the sim's `placeRoads`; the stop rule lives in the view controller for now, may move to the sim at M3 or M5 |
| 2026-10-29 | Map layer's scale and position are set from the tested camera model                             | Screen mapping matches camera.ts exactly, without depending on Phaser's own camera zoom origin                                           |
| 2026-10-29 | Roads drawn as discs at tile centres plus bars between adjacent pairs                           | Rounded joins and corners with one opaque fill colour; no overlap artefacts                                                              |
| 2026-10-29 | Debug overlay reads the sim's own road graph, never a copy                                      | The overlay shows what the sim holds, and tests check it covers every road tile and matches a full rebuild                               |
| 2026-10-29 | Tick rate is measured from sim ticks over one-second windows                                    | Shows real simulation speed, not frame rate; catch-up ticks are counted                                                                  |
| 2026-10-29 | Overlay toggles with D; tick text sits in screen space                                          | Keeps the text readable at any zoom; a temporary binding until the HUD exists                                                            |
| 2026-10-29 | Buildings occupy one tile; entrance faces one side                                              | Matches the grid model; connection is a shared edge with a road, same rule as roads                                                      |
| 2026-10-29 | A building can be placed before its road; it is only connected once a road touches its entrance | Lets the player plan layouts, and matches the plan's "entrance must connect to a road" wording                                           |
| 2026-10-29 | Roads refuse building tiles inside `placeRoads`                                                 | The sim owns the rule, so the view can't bypass it                                                                                       |
| 2026-10-29 | A* runs over road tiles, not graph edges                                                        | Same network at tile resolution; simpler to get right now; per-edge costs can come with congestion in M5                                 |
| 2026-10-29 | Route repairs keep only the route ahead of the car                                              | Tiles behind a car may be deleted without affecting it; keeping them would produce invalid routes                                        |
| 2026-10-29 | A car with no route home vanishes                                                               | Follows the spec decision for stranded cars; the player's choice in the original is not confirmed, so tune at Checkpoint A               |
| 2026-10-29 | Each tile is one lane; a junction holds one car at a time                                       | Simple, deterministic queuing and yielding without a per-lane model; cars already on a junction win over entrants                        |
| 2026-10-29 | Movement is front-first each tick, ties on car id                                               | Followers see the leader's new position, so the result is the same run to run                                                            |
| 2026-10-29 | Cars keep their in-tile position when rerouted on the same tile                                 | The car has not left its tile, so moving it back to the tile's centre would look like a jump                                             |
| 2026-10-29 | Each house owns a fixed number of cars; a lost car reduces that number                          | Keeps car count a real resource and makes losing a car visible; cars belong to houses as the plan says                                   |
| 2026-10-29 | Destinations are picked with equal chance until M4 demand                                       | Spawn weights are demand-driven in M4; until then equal chance keeps the test map simple                                                 |
| 2026-10-29 | Parked cars block their entrance tile                                                           | Queues form behind a parked car; the parking space is the entrance tile until M9 draws lots                                              |
| 2026-10-29 | Car dots are coloured by house, drawn every frame                                               | Cars move every tick, so drawing is per frame; colour shows which house a car belongs to                                                 |
| 2026-10-29 | Roads are two lanes; a car's lane is its direction of travel on the tile                        | Cars keep to the right, so opposite traffic passes freely; junctions stay one car at a time, as the lane rule doesn't apply there        |
| 2026-10-29 | Cars are drawn a quarter road width right of the centre line, inside the lane                   | Shows the lane without changing the road shape; the dot radius stays within the lane so cars never overlap the centre line               |
| 2026-10-29 | Roads link through corners as well as edges (diagonal roads)                                    | Players asked for 45° roads; a corner step is √2 long, so routing and movement use it, and the road graph follows the same rule          |
| 2026-10-29 | A 2×2 block of roads is four linked junctions                                                   | Corner links make all four tiles touch each other; the one-car-at-a-time junction rule already covers this                               |
| 2026-10-29 | A diagonal drag places a diagonal road; no filler tiles                                         | With corner links a diagonal road is a valid road, so the stroke no longer needs stairs                                                  |
| 2026-10-29 | A stroke takes a tile only when the pointer settles within 0.25 tiles of its centre             | Passing a corner no longer leaves stray tiles, so diagonal drags stay diagonal; a press still takes the tile under it at once            |
| 2026-10-29 | Demand pins are used up on arrival; a pin is claimed while its car drives there                 | A house sends only to a destination with an unclaimed pin, so one pin never sends two cars; a car that goes home keeps its pin           |
